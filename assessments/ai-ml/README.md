# AI/ML assessments

Use `interview-bank.md` for the active week's conceptual, debugging, design,
live-implementation, and delayed-transfer prompts. Attempt before revealing
answers. The bank is generated from the weekly syllabus; do not hand-edit it.

For each actual assessment, preserve:

1. Date, curriculum day, question, and actual learner answer.
2. Named rubric dimensions, individual scores, denominator, and reasoning.
3. Corrections, misconception category, follow-up attempt, and evidence links.
4. Implementation and real test output where executable practice is required.
5. Specific gaps, actual-date recall targets, and exact next unanswered task.

Use the 0-3 dimension rubric in the learning contract. Weekly assessments use
five dimensions, maximum 15; narrow quizzes use only relevant dimensions.
Do not mark unanswered prompts or untested implementation work as mastered.

Session transcripts/summaries belong under `sessions/ai-ml`, with summaries
labeled as such. Record user questions as well as assistant questions. The
structured tracker retains actual graded attempts and generates its scorecard.
No learner answers or completed assessments exist at plan setup.
